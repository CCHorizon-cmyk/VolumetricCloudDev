Aerial Volume Light / 空气散射体积光
光源空间透射率 RT 会始终以摄像机为中心自动跟随：每帧都令 RT Center = Camera Position，因此你调分辨率时不会破坏中心对齐。
AIR SCATTERING / 空气介质
Light Field 本身只由云体生成：R=云遮挡后的总太阳透射度，G=达到目标透射度附近的加权命中深度，B=命中可信度。最终体积光不再属于云 Density；主视线沿“空气”独立积分，根据当前位置在加权命中深度的前/后得到太阳可见度，再产生空气单次散射。云只是遮光体。RT 分辨率现在可单独调整，而且 RT 中心每帧锁定在摄像机位置。当前默认采用 256²×2 atlas、12 步光源空间 RT，并使用最新空气散射参数。

Density / 光学参数
HG 相位函数现在作为独立的加性方向散射项，不再乘在 Direct 上。Direct 只由太阳透射、Direct Strength 与 Powder 控制；Phase Strength 单独控制前向散射亮度。
MS Curve / 多散射光照闭包
直射光始终保持 exp(-OD)。这里只替换多散射附加项。两种曲线模式都使用当前 light ray 已经积分出的 OD，不会增加 Density 采样。
Polynomial
Exp-Polynomial
Polynomial: MS = (1 - Tdirect) × Gain × max(C0 + C1·OD + C2·OD² + C3·OD³, 0) Exp-Polynomial: MS = (1 - Tdirect) × Gain × exp(-max(C0 + C1·OD + C2·OD² + C3·OD³, 0))
Phi Fwd / 漫射场
沿现有太阳中心线同步累计 phi_fwd：不做锥形采样。当前默认采用较克制的漫射参数（Intensity 0.25 / ω0 0.981 / MS Build 0.20），避免厚云内部被过度奶白化；另外加入了阴影保持项，避免 phi 把局部阴影完全洗平。
Motion / 采样偏移
Weather 改为世界空间宏观尺度：默认约 180 km 一个主分布周期，并用 m/s 表示天气带平移速度。Detail Drift 仍只作用于 fBm / Worley / erosion，因此宏观天气和局部细节运动完全解耦。
Advanced / Upper Density 密度链隐藏参数
4 级 fBm 现已拆成独立频率控制：Octave 0–3 分别直接采样，不再强制使用固定 lacunarity。默认值沿用原先 base=0.035、ratio≈2.03 的链条。
