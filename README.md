## 当前参数

主光线预算 168 步，输出倍率 0.9，4× TAAU；光源步进 20，嵌套阳光 10，光空间 128→1024。视角滤波 1.5 px，光空间滤波 4 texel；漫射积分上限 4 km，局部积分端点查询默认关闭。闪电默认关闭，自动闪电预设频率 60 次/分钟。

移植要求：普通参数修改保留视角与光空间 TAA 历史；只有导致实际 RT 重新分配的参数变化才清空受影响历史。
